📊 Metrics · what shifts

  • Above-fold service visibility (760px viewport): 0 → 2-3 services
  • Trust signals visible above fold: 3/10 → 8/10
  • Tap-to-payment (real-price service): 5 taps → 3 taps (-40%)
  • Patronizing copy on page: 1 line → 0 (-100%)
  • Reading speed for shop name: +10–15% (italic → upright)
  • "All-สอบถามราคา" worst-case (Bubbie): dead end → LINE-redirect hero · saves the page
  • Visual weight of false-affordance blue duration: bold accent → muted meta · removed

🛠 Implementation order · ~3 hours total

  • Block 1 (~1 hr): typography swap (italic → upright) · meta rail (drop trust line, add inline meta) · status with closing time · address line
  • Block 2 (~1 hr): service card compress (110 → 80px) · tagline merge logic · duration de-emphasize · inline จอง CTA
  • Block 3 (~1 hr): 3-icon quick actions row · all-ask LINE-redirect hero · stock-photo hide-when-default · 1/N photo counter
  • Skipped for next sprint (cross-team): ✓ verified badge plumbing (needs backend listing endpoint to surface approve_data) · 5-photo gallery (needs /shop-setting upload UI) · LINE icon when lineOaId field added to backend
