🛠 Component design · <MenuPhotoCta />

Reusable React component · same OCR pipeline as menu-ocr.html · 1 source of truth 

// shop-frontend/src/components/menu-ocr/MenuPhotoCta.tsx

interface MenuPhotoCtaProps {
  onExtracted: (services: ExtractedService[]) => void;
  variant?: 'card' | 'inline';   // card = full visual · inline = subtle
  tipText?: string;
  testId?: string;
}

// Usage on /signup/service:
<MenuPhotoCta
  variant="card"
  onExtracted={(services) => mergeIntoForm(services)}
/>

// Usage on /services dashboard (subtle):
<MenuPhotoCta variant="inline" />

Pipeline shared with menu-ocr.html:
1. compressForOcr(file) · iter6.4 client-side resize
2. callClaudeVision(base64, mediaType, prompt) · same OCR endpoint
3. extractJsonFromText(response) · parse + validate
4. onExtracted(services) · caller decides how to merge
