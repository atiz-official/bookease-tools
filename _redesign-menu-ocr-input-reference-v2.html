📊 Layout 1 vs Layout 2 · which to ship?

Layout 1 (big above): visual prominence ดีสุด · merchant เห็นภาพชัด · เข้าใจทันที. Trade-off: กิน vertical space · ต้อง scroll หา dropzone.

Layout 2 (side-mini + checklist): ⭐ ผมแนะนำ · ภาพ + criteria pair กันใน 1 row. Side-by-side compact · ทุกอย่างใน 1 viewport · merchant ดูภาพ + อ่าน checklist พร้อมกัน · ประหยัด space.

Caravan reasoning:

1. Art ชี้ภาพ → "ถ่ายแบบนี้นะคะ" · merchant เห็น blueprint ทันที
2. Art อ่าน checklist 3 ข้อ → "มีชื่อ + ราคา · แสงพอ · ตรงๆ" · merchant zero-confusion
3. Merchant กดถ่าย → upload → OCR success rate สูงขึ้น (เพราะ blueprint guide framing)
