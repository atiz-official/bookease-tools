Verdict · ตัดสินใจ

❌ ทำไมไม่ควรใช้ palette-accent บน CTA
Beauty = #c98c80 fails contrast (2.8:1)
Wellness = #6b8e7f barely passes, gลืนกับ bg
Nail/Cafe = pops less than black on warm bg
Salon = same as black, ไม่ได้อะไรเพิ่ม

Root cause: palette colors were designed for atmospheric large areas (cover canvas) — not interactive UI chrome. Same color reads differently at 4:5 hero vs 48px button.
✅ ทำอะไรแทน
CTA stays black always — the commit action must be universal, high-contrast, predictable. Apple Pay button doesn't change color per merchant.

Variant expresses on:
· Page background color (--pal-bg) ✓
· Selected chip border color (subtle tint)
· Cover canvas · brand mark colors ✓
· Service card border/tint ✓
NOT on: CTA button fill, /payment chrome
Exception: chip selected state can use a very dark (≥7:1) version of --pal-deep. For beauty: use --pal-text (#4a1f1a) not --pal-deep (#c98c80). But at that point it's just "dark" — black is simpler.
