🧬 The Elon synthesis · what each contributes to v7

"Be the best on every dimension. Borrow the best implementation of each from whoever ships it best."
From Wongnai

Compact header

Brand · search · location collapsed into ~2 rows total. Saves ~80px of prime real estate vs our current 3-row stack.

From Wongnai + Art

Text+underline category nav

Confirmed: both Wongnai's sub-tabs and Art's v6 lock use the same pattern. Industry-validated.

From Gowabi

★ rating + review count

Trust signal next to name. Renders only when shop has >1 real review. Hidden gracefully for new shops.

From Gowabi

Trust badge (top-right of photo)

"ใหม่" for shops <30 days · "ยอดนิยม" for shops >X bookings · "Verified" for KYC-passed.

From Klook + Pass 25

Variant theme as italic sub-line

"a luxe escape" or "light & airy" under shop name · Cormorant Garamond · already in /payment trust strip · brand-coherent premium feel.

From Booking.com + BookEase

"ว่างวันนี้ ▾" as primary filter

Industry leaders use time as filter (set dates → see hotels). NO competitor in this audit uses availability for the marketplace home — our unique edge.

From Gowabi + Wongnai

Specific neighborhood label

"เอกมัย" "ทองหล่อ" "อโศก" — specific district, not just distance. Thai customers think in neighborhoods, not km.

All competitors

Photo-first density

Every winner leads with hero photos · 60%+ of card area. v7 keeps the 4:5 ratio so photo dominates without dominating scroll.

★ V7 · the synthesis

Every choice traces back to an industry-best behavior + Art's locked principles. No invention for invention's sake.
01 · HEADER

Brand + location + search in 2 rows

Wongnai's compact pattern. Eyebrow + wordmark + 🔍 ♡ icons row 1 · location bar row 2 (with count pill).

02 · CATEGORIES

Text line, underline-active

v6 lock confirmed by Wongnai. ทั้งหมด · เสริมสวย · นวด/สปา · เล็บ · ความงาม · ›

03 · TIME FILTER

"ว่างวันนี้ ▾" (BookEase unique)

Emerald gradient pill · the discriminator no competitor has. Sets the availability window for the whole feed.

04 · CARD · BADGE

Trust badge top-right of photo

"ใหม่" · "ยอดนิยม" · "Verified" · only when data justifies it. Gowabi pattern.

05 · CARD · NAME

15px/800 prominent (v6 lock)

Larger + heavier than meta · distance right-aligned on same row.

06 · CARD · VIBE TAG

Variant theme as italic sub-line

"a luxe escape" or "light & airy" · Cormorant Garamond · premium feel · differentiates shops with the same category.

07 · CARD · META

Category · price · neighborhood

"สปา · ฿890+ · เอกมัย" · district replaces abstract distance for Thai mental model.

08 · CARD · RATING

★ + review count when real

"★ 4.9 · 128" rendering only when ≥1 real review · gracefully hidden for new shops (show "✨ ใหม่" badge instead).
